# CET6 Buddy V1 前端界面设计说明

## 设计目标

移动端界面围绕“学习—回忆—订正—复习—打卡—同伴反馈”闭环设计。视觉气质轻松、可信、不过度游戏化；游戏得分、学习积分与知识掌握数据不混合表达。

## 信息架构

底部导航固定为五个主入口：今日、学习、闯关、小队、我的。答题和游戏页面进入沉浸模式，保留关闭、进度、保存状态与明确提交动作。管理后台采用桌面侧栏布局。

## 视觉系统

- 主色：紫色 `#6D5DFC`，用于主操作、当前状态和学习进度。
- 辅色：蓝色表示听读，绿色表示完成与同步，橙色表示挑战和提醒。
- 圆角：卡片 20–30px，按钮 15–18px，形成友好而稳定的移动端触感。
- 触控：主要按钮与图标按钮最小 44×44 CSS 像素。
- 状态：不只依靠颜色，完成、同步、错误均同时提供文字或符号。

## 后续实现顺序

先组件化视觉原型与路由，再接入登录、今日计划和学习会话；随后实现答题提交、订正和复习队列；最后接入游戏、小队、上传与管理后台。所有服务端确认前的成绩都应显示待同步状态。
